# Python ABL Assignment — Algorithms

Step-by-step algorithms for all 10 case studies. These use beginner-level Python concepts from Units I–III: input/output, variables, type conversion, arithmetic operators, conditional statements, loops, strings, lists, tuples and sets.

## 1. Simple Arithmetic Calculator

1. Start.
2. Read the first number.
3. Read the second number.
4. Calculate the sum, difference and product.
5. Check whether the second number is zero.
6. If it is zero, display that division is not possible; otherwise, calculate and display the quotient.
7. Display the sum, difference and product.
8. Stop.

## 2. Student Marks and Grade Calculator

1. Start.
2. Read the student's marks.
3. Calculate the total marks.
4. Calculate the average using the number of subjects.
5. Compare the average with the grade limits used by the program.
6. Assign the appropriate grade using if-elif-else statements.
7. Display the total, average and grade.
8. Stop.

## 3. Electricity Bill Calculator

1. Start.
2. Read the number of electricity units consumed.
3. Check whether the units are negative.
4. If the units are negative, display an invalid-input message.
5. Otherwise, determine the applicable rate or slab according to the program's billing rules.
6. Calculate the bill amount.
7. Display the bill amount.
8. Stop.

## 4. Temperature Converter

1. Start.
2. Ask the user to choose the conversion direction.
3. Read the temperature value.
4. If converting Celsius to Fahrenheit, calculate Fahrenheit = (Celsius × 9 / 5) + 32.
5. Otherwise, if converting Fahrenheit to Celsius, calculate Celsius = (Fahrenheit − 32) × 5 / 9.
6. Display the converted temperature.
7. Stop.

## 5. String Analyzer

1. Start.
2. Read a string from the user.
3. Find and store the length of the string.
4. Convert the string to uppercase.
5. Convert the string to lowercase.
6. Count the characters and words if those features are included in the program.
7. Display the analysis results.
8. Stop.

## 6. Palindrome Checker

1. Start.
2. Read a word or string.
3. Reverse the string or compare its characters from opposite ends.
4. Check whether the original string is equal to its reverse.
5. If both are equal, display that it is a palindrome.
6. Otherwise, display that it is not a palindrome.
7. Stop.

## 7. Star Pattern Generator

1. Start.
2. Read the number of rows.
3. Initialize the row counter.
4. Check whether the row counter is less than or equal to the number of rows.
5. If true, print the required number of stars for that row.
6. Move to the next line.
7. Increase the row counter and repeat Step 4.
8. Stop when all rows have been printed.

## 8. List Statistics Calculator

1. Start.
2. Read the list elements from the user.
3. Initialize the total and count.
4. Traverse the list using a loop.
5. Add each element to the total and update the minimum and maximum values.
6. Find the average if the list is not empty.
7. Display the count, sum, minimum, maximum and average.
8. If the list is empty, display an appropriate message instead of calculating the average.
9. Stop.

## 9. Student Record Using Tuples

1. Start.
2. Read the student's name.
3. Read the roll number.
4. Read the marks.
5. Store the details in a tuple.
6. Unpack the tuple values if required.
7. Display the student's record.
8. Stop.

## 10. Set Operations and Duplicate Removal

1. Start.
2. Read the elements for the first collection.
3. Read the elements for the second collection.
4. Convert the collections into sets to remove duplicate elements.
5. Find the union of the two sets.
6. Find the intersection of the two sets.
7. Find the difference of the first set from the second set.
8. Display the sets and the results.
9. Stop.

## Notes

- These algorithms describe the intended logic of each case study in numbered form.
- Use the exact grading boundaries and electricity rates implemented in the corresponding project's source code.
- Follow the actual program's supported input choices when running each case study.
